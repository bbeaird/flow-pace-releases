Flow Pace Privacy Policy

Effective 2026-10-23 · Developer: Brantley Beaird

What stays on this Mac

  • Microphone audio is analyzed in memory and never saved.
  • Speech is recognized by Apple’s on-device recognizer. Flow Pace requires on-device recognition and has no cloud fallback.
  • Session numbers (word counts, timings and your review labels) are saved in ~/Library/Application Support/com.brantleybeaird.flowpace/. Settings and recent error codes are saved in the app’s preferences.
  • Transcripts are saved only if you turn on Keep transcripts for calibration. It is off by default.
  • To tell dictation from Notetaker, Flow Pace reads Wispr Flow’s process, microphone and window state on this Mac, never your dictated text.
  • CSV exports go only where you save them.

Usage analytics

Usage analytics are on by default. On a new install, nothing is sent before the setup step has been shown. Flow Pace sends these events to Segment, which forwards them to Google Analytics:

  • app_opened: once per launch, and when you turn usage stats back on.
  • screen_view: when the dashboard appears, with screen_name “dashboard”.
  • comparison_exported or comparison_export_failed: when a CSV export succeeds or fails.

Each event also carries app (“flow-pace”), platform (“macos”), app_version, environment (“production”), session_id (the time the app started or usage stats were turned back on), engagement_time_msec (always 1), an event ID and a timestamp.

Each event includes a random identifier. It is created when the app starts, kept only in memory, and replaced when you turn usage stats off and on. Events from one launch share it, so they can be linked to each other.

Segment and Google Analytics see the IP address of the requests they receive. Flow Pace sets the IP field inside each event to 0.0.0.0. It never sends audio, transcripts, pace numbers, file names, or device or advertising IDs.

To turn it off, untick “Shares anonymous usage stats.” in the setup step, or turn off Share usage stats in Details › Settings. This stops future sends. It does not delete events already sent.

Privacy policies: Segment (Twilio) and Google.

Other network connections

None. Flow Pace has no update checks, accounts, ads, or AI, cloud or lookup services. The Privacy Policy link in Settings opens this page in your browser.

Contact

Open an issue at https://github.com/bbeaird/flow-pace-releases/issues. Issues are public, so leave out private details.
